# Тесты на проверку параметра `name` в запросе на создание набора в Яндекс.Прилавок

API Яндекс.Прилавка, `Main.Kits → Создание набора`.

## Что проверяется

- Длина имени: от 1 до 511 символов - валидно, 0 и 512 — ошибка.
- Символы: английские и русские буквы, спецсимволы, пробелы, цифры.
- Неверные данные: число, отсутствие параметра `name`.

Ожидаемые коды: `201` — набор создан, `400` — запрос отклонён.

## Требования

- Python 3.8+
- Зависимости из `requirements.txt`

## Установка зависимостей

```bash
pip install -r requirements.txt


Запуск
Все тесты:
bash
pytest
